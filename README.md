# 宮崎発 たび日和

宮崎在住の夫婦が、旅行の計画段階でつまずきやすいところを書いているページです。

観光地の紹介ではなく、**日程を組むときに知らないと計算が狂うこと**を中心にまとめています。

- 宮崎は縦に長い
- 新幹線は通っていない
- レンタカーはほぼ前提
- 1泊だと県北か県南のどちらかしか回れない
- 高千穂は「宮崎市の近く」ではない
